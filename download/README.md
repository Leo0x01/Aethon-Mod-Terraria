# 📦 Aethon_Entrega_Final.zip

Este archivo contiene la entrega final del proyecto "Aethon, la Luz Primordial".

## Contenido

### 1. `Aethon_Diseno_Del_Mod.pdf` (429 KB · 31 páginas)
Documento de diseño completo del mod, en español, con tema cósmico:
- **Documento de Diseño del Mod** (18 secciones): visión, entidad cósmica, altar/fragmento, sistema de 3 ramas principales, sub-ramas del árbol, niveles infinitos, árboles procedurales, absorción de lore, sistemas del mundo, jefe final Aethon, jefes secundarios, economía, NPCs, compatibilidad, identidad visual.
- **Roadmap de Implementación** (anexo): 15 fases para crear el mod real en C# con tModLoader, ~40 archivos, APIs clave, estimación de esfuerzo (44–61 días).

### 2. `Aethon_Sitio_Web.html` (151 KB · autocontenido)
Sitio web showcase en un único archivo HTML autocontenido:
- Todas las imágenes embebidas en base64 (no requiere archivos externos).
- CSS del tema cósmico inline.
- Captura visual del sitio con las 3 ramas principales (Lumina/Solbrand/Grimorio).
- ⚠️ **Nota**: Es una captura estática del HTML renderizado. Las funciones interactivas
  (selector de armas, calculadora, árbol de habilidades, códex) NO son funcionales en este
  archivo — son capturas visuales. Para la experiencia interactiva completa, ejecuta el
  proyecto Next.js (`bun run dev` en `/home/z/my-project`).

## Cómo usar

1. **PDF**: Ábrelo con cualquier visor de PDF (Adobe Reader, navegador, etc.).
2. **HTML**: Ábrelo con cualquier navegador moderno (Chrome, Firefox, Safari). Doble-click.
