The '''Murasama''' is a post-[[Moon Lord]] [[melee weapon]]. It can be found in [[The Underworld]]'s [[Arsenal Labs#Underworld Bio-center Lab|Bio-center Arsenal Lab]], contained within a [[Security Chest]].

Although the Murasama is technically obtainable in [[Pre-Hardmode]], it cannot be swung until [[The Devourer of Gods]] has been defeated in the current world. In this unusable state, it will have a "sheathed" appearance in which the blade is covered by a mechanical exterior.

After the Devourer of Gods is defeated, the item's appearance changes to reveal the glowing red blade, and it is now capable of being swung. When used, it swings large red electric slashes in the direction of the cursor. The slashes appear in a set looping order: A downwards slash, then an upward slash, and then it wraps back around to do a giant upward slash that deals double damage. The Murasama emits bright red particles outward when it hits something.

== Notes ==
*In the [[Get fixed boi]] seed, the Murasama receives a 200% size modifier, and it can deal damage immediately when used, allowing it to be spam-clicked for rapid damage.
*The Murasama's unlock state is dependent on whether the Devourer of Gods has been defeated in the currently played world. Bringing an unlocked Murasama to a world where the Devourer of Gods has not been defeated will cause it to become unusable again.

== Trivia ==
*The Murasama is a reference to a weapon of the same name and similar appearance wielded by the character Jetstream Sam from ''{{wikipedia|Metal Gear Rising: Revengeance}}''.
**The weapon's tooltip, "There will be blood!", is a reference to the line "The only thing I know for real- There will be blood! Shed!" from Sam's boss theme, "The Only Thing I Know For Real".
*The first frame of the Murasama's slash animation has a Crewmate from the game ''{{wikipedia|Among Us}}'' hidden in it. [[File:Murasama Crewmate Easter Egg.png|thumb|The hidden Crewmate easter egg. (Blue circle added for visibility)]]
